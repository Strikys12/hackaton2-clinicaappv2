#  Instrucciones para ejecutar el proyecto

1. Clonar o descargar el repositorio desde GitHub
2. Abrir IntelliJ IDEA
3. Seleccionar: File → Open
4. Seleccionar la carpeta principal del proyecto: hackaton2-clinicaappv2
5. Ejecutar el método main
6. Los datos y las opciones del sistema se ingresan directamente por la consola de IntelliJ IDEA
7. Seguir las instrucciones que aparecen en la consola para interactuar con el sistema.
